# tm-dev-pro.github.io

Personal website of **Tarun Mittal** — Senior Software Engineer (Python, Go, distributed systems, agentic AI).

Live at: **https://tm-dev-pro.github.io**

## Stack

Plain HTML / CSS / JS. No build step. Deployed automatically to GitHub Pages by the workflow in `.github/workflows/deploy.yml` on every push to `main`.

## Add your photo

Drop a square-ish photo at `assets/profile.jpg` and push — the site picks it up automatically (falls back to the TM initials avatar if missing).

## Update the resume

Replace `assets/Tarun_Mittal_Resume.pdf` with the latest compiled PDF from the `final-resume` repo (`output/resume.pdf`) and push.
